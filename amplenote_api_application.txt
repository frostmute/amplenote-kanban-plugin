Describe what you will build with API access. If you have an estimate for long until it will be ready, please include it:
I am building a "Markdown-backed Kanban boards" plugin for Amplenote, specifically targeting the active $2,500 bounty listed on the bounty board. The plugin converts a markdown note into a visual Kanban board where columns are headings and tasks are cards. It features bi-directional sync (dragging a card updates the underlying markdown section using `app.replaceNoteContent`), rich footnote/image rendering, and optimistic UI updates via a React frontend running in `renderEmbed`.

I have already scaffolded the architecture as a mono-repo combining an AST markdown parser (`mdast-util-from-markdown`) for strict block mapping and a React/Vite-bundled SPA for the frontend UI. 

Estimated timeline: A functional MVP should be ready within 1-2 weeks.
